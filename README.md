# CustomCalc — кастомизируемый калькулятор для Android

Kotlin + Jetpack Compose, minSdk 28 (Android 9+).

## Как запустить
1. Установи Android Studio (Koala 2024.1 или новее).
2. `File → Open` и выбери папку `CustomCalc`. Подожди, пока пройдёт Gradle Sync (нужен интернет).
3. Подключи телефон (отладка по USB) или запусти эмулятор и нажми ▶ Run.
4. Для установочного файла: `Build → Build APK(s)`.

## Что умеет
- Калькулятор: + − × ÷ %, скобки, десятичные, живой предпросмотр результата, ⌫ и AC.
- Фон — любое фото из галереи (копируется внутрь приложения), размытие и затемнение.
- Без фото — градиент любых двух цветов.
- Свои цвета (палитра + RGB-ползунки) для акцента, кнопок, текста.
- Прозрачность, скругление, отступы, размер шрифта.
- Эффекты: свечение, «стеклянная» рамка, пружинная анимация нажатия, частицы (круги / конфетти / искры), вибрация.
- Готовые темы: Стекло, Неон, Тёмный, Закат.
- Все настройки сохраняются.

Настройки открываются кнопкой ⚙ в правом верхнем углу.

## Структура
- `CalcEngine.kt` — парсер выражений и логика ввода
- `Settings.kt` — модель стиля, темы, сохранение, хранение фото
- `Effects.kt` — система частиц
- `CalculatorScreen.kt` — экран, кнопки, анимации
- `SettingsSheet.kt` — панель настроек
